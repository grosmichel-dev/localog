# 구글폼 사양 (intake-form-spec)

참여자가 자료를 제출하는 구글폼의 질문 구성입니다. 각 질문은 `docs/DATA-STANDARD.md`의 필드에 1:1로 대응합니다.
폼을 만들거나 고칠 때 이 표와 어긋나지 않게 유지하세요.

## 1. 질문 목록

| # | 질문(폼에 표시) | 유형 | 필수 | 대응 필드 | 비고 |
|---|---|---|---|---|---|
| 1 | 날짜 | 날짜 | 필수 | `date` | 자료에 적힌 날짜 (YYYY-MM-DD) |
| 2 | 담당 부서 | 단답 | 필수 | `department` | 원문 표기 그대로 |
| 3 | 올린 곳(출처유형) | **드롭다운(4개 고정)** | 필수 | `source_type` | `구청 공지사항` / `고시공고` / `구청장회의(유튜브)` / `구의회 회의록`. 자유입력 금지: 표기가 갈리면 자동 분류가 깨짐 |
| 4 | 제목 | 단답 | 필수 | `title` | 원문 그대로 |
| 5 | 키워드 | 단답 | 필수 | `keywords` | 쉼표로 구분, 최대 8개 |
| 6 | 원문 주소 | 단답(URL) | 필수 | `source_url` | `http(s)://`로 시작 |
| 7 | 본문 | 장문 | 필수 | (본문) | 원문 복사·붙여넣기. 요약·수정 금지 |
| 8 | 관련 근거 | 단답 | 선택 | `관련근거` | 원문에 적힌 문서번호 그대로 (예: `대덕구-청년정책과-2026-0517`) |
| 9 | 사진 첨부 | 파일 업로드 | 선택 | (`assets/` 후보) | 현장 사진 + 한 줄 설명 |

## 2. 폼 안내문에 넣을 문구

- "일반 시민(민간인)의 이름·연락처가 보이면 가리고 올려 주세요. (공무원·의원의 공적 발언은 괜찮습니다)"
- "내용을 요약하거나 다듬지 말고 원문 그대로 붙여 주세요."

## 3. 폼 설정

- **이메일 수집: 끔.** 응답자의 개인정보를 우리가 갖지 않기 위해서입니다.
  (파일 업로드 문항은 구글 정책상 로그인이 필요할 수 있습니다. 그 경우에도 이메일을 응답 데이터로 저장하지 않게 설정하세요.)
- 응답 수정 허용은 꺼도 됩니다. 고칠 것이 있으면 재제출이 단순합니다.

## 4. 응답 처리 위치 (중요)

- 응답과 첨부파일은 **저장소 밖 로컬 `inbox/` 폴더**로 내려받아 처리합니다.
- 미검토 원본에는 개인정보가 있을 수 있어, git 저장소 안에 두면 실수 한 번으로 공개될 수 있기 때문입니다.
  `inbox/`는 저장소 밖이라 push가 물리적으로 닿지 않습니다.
- 검토·마스킹·서명을 마친 것만 저장소로 옮겨 PR로 올립니다. 흐름은 `docs/COMMIT-FLOW.md`.
- 접수·로그인·본인인증 같은 시스템은 만들지 않습니다. 그런 업무는 행정(구청)의 몫입니다.
