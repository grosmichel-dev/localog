# 원천 자료 실측표 (source-availability-check)

파일럿에 쓸 자료가 실제로 어디에, 어떤 포맷으로 공개돼 있는지 운영자가 직접 게시판을 열어 보고 채우는 표입니다.
이 표가 채워져야 입력 파이프라인과 파일럿 콘텐츠 작업을 시작합니다. (문서에 없는 자료는 계획할 수 없기 때문)

- 점검 대상 기간(절대 날짜): **2026-01-01 ~ 2026-06-30** (기본값. 기간을 넓히면 아래 판정 절에 새 기간을 적으세요)
- 점검일: (작성 필요: YYYY-MM-DD)
- 점검자: (작성 필요: 핸들)

### 판정 규칙

1. **사용 가능한 비HWP 자료가 10건 미만이면** 날짜 범위를 넓혀 다시 점검합니다. (예: 2025-07-01부터)
2. **원천의 상당수가 HWP 전용이면** 사이트에 "커버리지 갭" 고지를 싣고, HWP 변환은 v2로 미룹니다.
   일부만 실은 채 "대덕구 행정을 대표하는 아카이브"라고 주장하지 않기 위해서입니다. (HWP 자동 변환은 파일럿 범위 밖)
